# Assets visuais

## Imagens de marca

- `images/icons/logo.png` — logotipo (coroa de louros + ampulheta). Usado como favicon e ícone de app.
- `images/icons/laurel-crown.png` — coroa de louros em PNG com transparência, usada na tela de
  boas-vindas (tingida por CSS para o ouro velho da interface).

## Vetores originais (CC0)

A cena de fundo e a ampulheta da tela de foco são **vetores originais criados para este projeto**,
sob dedicação ao domínio público (CC0 1.0): podem ser copiados, modificados e redistribuídos sem
atribuição.

- `#art-rome-skyline` — paisagem romana (templo, aqueduto, ciprestes, colinas e sol), definida como
  `<symbol>` no `index.html` e usada como cenário de fundo.
- `#clepsydra-template` — ampulheta (clepsidra) com areia animada, moldura de bronze e virada de fase.

Ambos usam as variáveis de cor de `css/settings.css`, portanto acompanham o tema claro e escuro.
